# Sentinel Identity

Identity and access management dashboard.

## Features

- Users and permissions
- Audit log

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/sentinel-identity-shield.git
cd sentinel-identity-shield
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
